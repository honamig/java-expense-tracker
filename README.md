# Java Expense Tracker

This project is a simple expense tracker created in Java. The purpose of this project is to learn and practice Java programming concepts such as variables, data types, methods, user input, classes and objects, ArrayLists, and file handling.
The final application will allow users to add and display expenses, organize them by category, calculate total expenses, and save expense data.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Install the Java Development Kit (JDK)
2. Clone this GitHub repository to your computer
3. Open the project folder in VS Code or another Java-compatible IDE
4. Compile the program using javac Main.java
5. Run the program using java Main

Instructions for using the software:

1. Run the program and follow the menu displayed in the terminal
2. Select an option to add or view expenses
3. Enter the requested expense information, such as the name, amount, and category
4. Use the menu options to view expenses and calculate the total
5. Exit the program when finished
